# Mongolia Destinations

Premium English-language intro site for three Mongolian tourist camps.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis
- Swiper

## Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Customize
Edit `data/destinations.ts` to replace the placeholder camp names, descriptions, images and accent colors with the real camp information.
